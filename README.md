**what it it:**

* so basically it is an split keyboard and has 15 keys on each side and design to comfort the user and also to understand matrix system i use esp32wroom32D development boards and make a custum firmware and i forget to tell you that it operates wirelessly.

**FEATURES:**

* IT features an Esp 32 development board because its cheap and easily available on any online hardware store.
* it has 15 keys on each sides.
* it features wireless communication
* it has diodes to prevent from ghosting.
* i use hierarchal sheets in schematics for not wasting time\
* i also pick one of the best pins on esp32 module.
* its PCB offers breakoff
